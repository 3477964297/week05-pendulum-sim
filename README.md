## 实现说明

- 单文件应用，HTML / CSS / JavaScript 全部内联，不引用外部库或网络资源。
- 背景采用深灰科技色 `#1a1a24` 所在的色阶，摆球带青绿色辉光。
- 物理方程：`α = -(g / L)·sinθ - k·ω`，固定步长 240 Hz，四阶 Runge–Kutta 积分。
- 摆长以像素表示，重力按 100 px/m 映射到画面尺度，保证课堂演示中周期可见。
